# DIAZAI 12 Superplane Atlas v1.0

Canonical principal seeds:
- X=(0,1,2)
- Y=(0,1,5)
- Z=(0,1,8)
- Lambda=(1,1,1)

Twelve full planes are the P^1(Z9) classes [1:t], t=0..8, plus [0:1], [3:1], [6:1].
Every matrix is i=r locked. Each plane has 6 horizontal unit-associated generators and the shared 6 vertical rotor generators ((1,1,1), (2,2,2), (4,4,4), (8,8,8), (7,7,7), (5,5,5)).
Thus: 36 coordinate gauges per plane; 432 across all twelve.

Exact ambient coverage:
- 648 states on exactly 1 full plane
- 72 states on exactly 3 full planes
- 9 Lambda-axis states on all 12 full planes

The companion XYZ 27x27 object is a separate 729-scalar-cell unfolding of the 243 X/Y/Z plane-cell triple occurrences: 3 planes × 81 triple cells × 3 scalar coordinates = 729 scalar cells. It is not the same object as the 729 unique ambient triples.

Generated deliverables in the v1.0 artifact package include PDF, DOCX, PPTX, XLSX, SQLite, JSON/CSV databases, PNG matrix renders, S3 orbit graph, incidence charts, and an exact generator script.
