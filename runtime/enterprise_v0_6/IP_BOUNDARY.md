# Public / Private IP Boundary

The DIAZAI repository is public. Files committed here are public disclosures and must not be treated as trade secrets.

Public-safe material includes interfaces, schemas, baseline adapters, self-tests, and benchmark methodology. Production policy calibration, customer traces, private telemetry quantizers, unpublished hardware/optical mappings, invention-disclosure material, and attorney work product must remain outside this repository.

The v0.6 public SDK intentionally does not finalize an open-source license for patent-sensitive DIAZAI implementation code. Licensing and patent strategy must be decided before any broader public release.
