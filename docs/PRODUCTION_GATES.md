# Production Gates

## Implemented in the executable reference package

- deterministic 729-state kernel and exhaustive bijection tests
- canonical X/Y/Z plane conformance tests
- exact RBS integer round trip with checksum
- request preview, policy enforcement, approvals, idempotency
- exact/compensating/nonreversible labels
- forward and reverse receipts with separate event and receipt chain verification
- SSE action stream, analysis snapshot, OpenAPI, offline UI fallback
- Docker and Hugging Face Docker Space packaging

## Required before a genuine enterprise GA claim

1. PostgreSQL transactional stores with migrations, tenancy, row-level isolation, retention, and backup restore drills.
2. OIDC/SAML, SCIM, RBAC/ABAC, managed keys, secret rotation, and signed release provenance.
3. Durable workflow/event infrastructure and idempotent connector workers.
4. TLS termination, WAF, network policies, egress allowlists, dependency/SBOM/container scanning.
5. OpenTelemetry SLOs, alerting, capacity tests, chaos/failover tests, and runbooks.
6. Independent penetration test and threat model; SOC 2 evidence program if sold into enterprise.
7. Versioned mathematical conformance corpus and independent replication of performance claims.
8. Explicit data and model governance, including PII handling and model-evaluation gates.

No dashboard label or hash chain substitutes for these controls.
